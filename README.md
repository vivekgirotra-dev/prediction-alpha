# Prediction Alpha

Real-time arbitrage detection for prediction markets (Kalshi + Polymarket).

## Features

- **Risk Profiles**: Conservative, Balanced, Aggressive
- **Kelly Criterion**: Optimal bet sizing based on edge
- **Traffic Lights**: Green (>3%), Yellow (2-3%), Red (<2%)
- **Deep Links**: One-tap to trade on Kalshi or Polymarket
- **Auto-refresh**: Scans every 30 seconds

## Quick Start
```bash
npm install
npm start
```

Then in another terminal:
```bash
cd web
npm install
npm run dev
```

Visit http://localhost:3000
